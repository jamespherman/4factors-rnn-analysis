# R01 core panels (Aim 1), 2026-11-01

Simple panels using the standard (original) analyses. Each folder: png/pdf, CSVs, stats.csv, standalone plot script.
- `P1_reward_x_expectation_psth/`: reward cue x expectation in classic SC neurons. Use **P1b** (expected minus
  unexpected, high vs low reward cue): the cue flips the sign of the expectation effect, mirroring behaviour (B1).
- `P2_factor_alignment_scatter/`: per-neuron effects; image vs salience aligned (r = +0.40, p = 4e-10, n = 226);
  location prior vs image not aligned (r = -0.05, n = 140). Alternative: reward vs salience (r = +0.09).
- `P3_suppression_by_angle/`: % units with pre-saccadic suppression by target angle (opposite targets most).
- `P4_bilateral_state/`: pre-target L-R SC state predicts choice (z 3.78, 2.32); flat cross-midline CCG.
