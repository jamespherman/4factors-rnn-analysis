Recovery pilot: can a model with one shared reward signal reproduce SC reward-context modulation?

Report on results/recovery_pilot and the verified-trial fits it calibrates (results/verified_grid). Newton SC sessions 08_13–08_15. Built 2026-10-14 from commit 25049c6 by scripts/make_recovery_report.py. Prepared by Claude for James Herman.

SC neurons fire differently before the target appears depending on which locations currently give a large reward, and the size of this reward-context effect differs reliably between neurons. If reward context reaches SC as one global signal, the local excitatory–inhibitory circuit must turn it into these neuron-specific effects; if it arrives already specific to each neuron, the circuit need not. When we fit E–I network models to the recordings, only models with a separate context input for each unit reproduced the neuron-by-neuron pattern. Because that contrast could reflect fitting limits rather than mechanism, we fit the same models to synthetic data from networks whose mechanism is known. This report presents that recovery pilot, one session, and what it does and does not establish.

On real data, per-unit context models reproduced the pattern (held-out r = 0.43, ceiling 0.64); shared-context models did not (+0.04). In the pilot, students recovered per-unit teachers' patterns, so the test can succeed. Shared-context students recovered much of a per-unit teacher's pattern when effects were large, but erratically at realistic effect sizes (+0.42 and -0.03 for two such teachers). A shared-context teacher, the control for whether the test can confirm a shared mechanism, turned out to have almost no reward-context effect of its own, so that control remains open. Per-unit students scored above zero even on a teacher with no context, raising the worry that their real-data success was generic. A control on the real data rules most of this out: with the context inputs shifted out of register with the trials, per-unit models fell from r = 0.43 to 0.13 (all units) and from 0.36 to -0.01 (I units only). The neuron-specific reward-context pattern is therefore genuinely carried by context that is aligned with the task, and per-unit context input reproduces it. Whether a single shared signal could also reproduce it remains untested, because the pilot has not yet shown that the procedure recovers a shared mechanism when that is the truth. The full test, on all re-exported Newton and Feynman sessions, is specified in Section 8.

1. The data: what the monkey did and which trials were analysed

SThe monkey fixated, then made a saccade to one target at one of four locations. Two context variables changed across a session in blocks (Fig. 1a, b). The reward map set which pair of locations gave the large reward (1 + 2, or 3 + 4). The probability block set which location was the frequent target (1 or 3). The reward map switched every 48 successful trials, 6–11 times per session (25 switches over three sessions); the probability block switched half as often.

SWe analysed 1185 of 1991 exported trials: the successful ones whose event times were verified against the task-control records (Fig. 1d). The original export also contained fixation breaks and trials with unreliable event times, and its reward times were 0.46–0.65 s late (trial audit by the pipeline session, data/trial_audit). The 109 neurons are 76 classic SC neurons, fit by excitatory (E) model units, and 33 putative interneurons, fit by inhibitory (I) units. That classification comes from the analysis pipeline.

2. The quantity: a neuron's reward-context effect, and how reliable it is

SFor each neuron and each reward-map switch, we took its mean firing rate in the pre-target window (−300 to 0 ms) over up to 30 trials after the switch, minus the same before it (Fig. 2a). The sign is positive when the neuron's preferred location became the large-reward location. Averaging over switches gives one number per neuron, its reward-context effect. Preferred location is the location of the neuron's largest visual response.

FThe effect differs between neurons, and that pattern is reliable. Neuron-to-neuron differences on 15% held-out test trials correlate with those on the remaining trials at r = 0.64 (Fig. 2c), which is the ceiling any model can reach on this test split. Across neurons the mean effect is small, +0.37 sp/s (Fig. 2b). This report is about the pattern across neurons, not the mean.

3. The models: what differs between variants, and that they fit

SEach model is a recurrent network of rate units obeying Dale's law (Fig. 3a). Every recorded neuron is fit by its own unit, E neurons by E units and I neurons by I units, and the network is padded with unrecorded E units to a 4 : 1 E : I ratio. The network receives the task events and eye position, three slow-drift inputs (smooth functions of trial number that absorb slow changes in firing over the session), and in most variants two context inputs. Variants differ only in how the context inputs reach the units (Fig. 3b): not at all; through one shared weight per population (all E units get the same drive, as do all I units); or through a separate weight for each unit. A shared input can still affect neurons differently, because the network's own connections route it.

SFitting adjusts all weights so the model's firing matches the recordings: trial-averaged responses per condition, single-trial variability, and mean pre-target and visual-window rates per location and context state. Trials were split once into fitting (70%), checkpoint selection (15%) and test (15%) sets, the same for every variant; each variant was fit 6 times from different random starts ("restarts"). Every r reported here is on the test trials.

4. Real data: only per-unit context reproduces which neurons are modulated

FAll variants fit the spatial tuning of the neurons well (Fig. 4b: mean r = 0.64–0.86), so the comparison is between models that fit the dominant structure in the data. They differ in the reward-context pattern (Fig. 4a). With per-unit context, models reached r = 0.43 (to all units), 0.36 (I units only) and 0.36 (E units only), against a ceiling of 0.64. With shared context they reached -0.04 to +0.04, no better than without context (-0.07). Fig. 4c–d show the neuron-by-neuron agreement for the best restart of each.

SHeld-out likelihood does not separate the variants: differences are a few thousandths of a log-unit per neuron per time bin, the same size as differences between restarts (table). The extra per-unit weights therefore do not improve the overall fit; they matter only for this small effect.

5. Why a recovery test, and how it works

SFigure 4 alone cannot show that a single shared reward signal is insufficient. A shared-context model might be able to produce the pattern and simply not have found it during fitting. Conversely, per-unit models have more free weights, and might match any reliable per-neuron pattern, including one unrelated to reward. A recovery test asks what the fitting procedure returns when the truth is known (Fig. 5). We took networks already fit to session 08_14 as teachers, generated spikes from them on the same trials, and fit students to those spikes exactly as on real data. Teachers differ in mechanism: no context; shared context; per-unit context to all units; per-unit context to I units only, so that any neuron-specific effect on E units must pass through the I→E connections. Multiplying a teacher's context weights by g = 3 makes its effects larger; g = 1 keeps them close to the recorded size.

6. Recovery results

FThe test can succeed: per-unit students recovered per-unit teachers at realistic size, r = 0.69 (all-unit teacher) and 0.77 (I-only teacher, I-only student), at or near the ceilings (0.66, 0.80). Students without context scored at or below zero on every context teacher, as they should.

FA shared signal can make neuron-specific effects. With large effects (g = 3), shared students recovered 0.93 of an all-unit teacher's pattern and 0.64 of an I-only teacher's: the network routes one common input into different effects in different neurons. At realistic size (g = 1) the same students were erratic: +0.57 +0.14 +0.56 and +0.72 -0.40 -0.41 across restarts.

FThe shared-context teacher could not serve as the shared-mechanism control. It came from the shared-context fit to 08_14, which had learned almost no context effect: at g = 1 its mean effect was -0.15 sp/s and its per-neuron pattern was barely reliable (ceiling 0.19). At g = 3 the pattern became reliable (ceiling 0.71), but students without any context input reproduced it as well (+0.72) as shared students (+0.79), so it reflects the teacher's drift and task structure rather than context.

FPer-unit students can score above zero without any reward context. On the no-context teacher, the effect measure was itself reliable (ceiling 0.50), because the teacher's slow-drift inputs change firing over the session, and switches happen at particular times. Per-unit students matched this drift-driven pattern with r = -0.17 +0.42 +0.22 (all units) and -0.03 +0.60 +0.25 (I only), using their context inputs as extra slow regressors.

7. The calibrated comparison

FOn real data, the per-unit models' success depends on correctly aligned context, so it is not the generic advantage seen on the no-context teacher. In a control, each context input was shifted by a quarter of its own period (24 trials for the reward map, 48 for the probability block): it keeps the same switching statistics but is uncorrelated with the true context. Per-unit models given these inputs reached r = +0.13 (all units; restarts +0.05 to +0.28) and -0.01 (I only; -0.40 to +0.15), against +0.43 and +0.36 with aligned context (Fig. 4a, gray columns); the ranges do not overlap. About 0.13 of the all-unit score is what extra slow inputs buy without real context.

FWhat the pilot cannot yet say is whether a shared signal could have produced the real-data pattern. On real data the shared student scored +0.04 against +0.43 for the per-unit student. On a per-unit teacher of realistic size the gap was smaller (+0.42 vs +0.69) for one teacher and similar (-0.03 vs +0.68) for the other (Fig. 7). So a large gap is what this procedure produces for at least some data generated by neuron-specific input, consistent with the real-data result, but it is not unique to such data: on the no-context teacher the per-unit student also outscored the shared one (+0.16 vs +0.12).

8. What this does not show yet, and what comes next

GapShared-teacher control still open. The teacher taken from a shared-context fit had almost no context effect (Section 6), so the test has not yet shown that it can confirm a shared mechanism when that is the truth. A usable shared teacher needs a sizeable, genuinely context-driven effect: for example, a shared-context network trained with the context effect weighted more heavily, checked against a no-context student before use.
GapOne session, three restarts. The pilot used 41 neurons from 08_14. Single-session r varies by about ±0.4 between restarts (Fig. 6), so the pilot calibrates the test but cannot settle it.
GapTeachers are themselves fits. Their mechanisms are realistic only to the extent that the fits are; a teacher whose context effects match the recorded pattern exactly does not exist yet.
GapDrift and context are partly confounded in this design, because switches happen at fixed intervals. The effect measure picks up slow drift (no-context teacher ceiling 0.50).
GapE versus I as the landing site of neuron-specific input is only weakly identifiable at realistic effect sizes: each teacher was recovered best by the matching student, but by small margins.

SNext, once the corrected exports arrive (Newton and Feynman, all sessions, outcome-filtered trials): refit all variants with 6 restarts; run the recovery test on every session with shared, all-unit, I-only and no-context teachers at realistic effect size; run the shifted-context control on every session; report the shared/per-unit gap on real data against its distribution across teachers.
