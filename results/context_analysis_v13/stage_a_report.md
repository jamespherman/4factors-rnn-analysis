## A1c. Probability sign reversal

Per neuron, block 1 minus block 2 visual response at location 1 (d1) and location 3 (d3). Location 1 is frequent in block 1 and location 3 in block 2, so a probability effect gives d1 and d3 opposite signs (tested by d1 - d3); drift shifts both the same way (d1 + d3).

n = 293 neurons; mean d1 = -1.10, mean d3 = +0.39 sp/s; probability component (d1 - d3)/2 = -0.74 sp/s, p = 9.3e-10; common component (d1 + d3)/2 = -0.35 sp/s, p = 0.056. Positive probability component = higher response when the location is frequent.
